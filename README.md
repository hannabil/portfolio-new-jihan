# Portfolio New Jihan - Walkthrough

Repositori ini berisi file sumber untuk website portofolio Jihan Nabila.

## 📁 Struktur File
- `index.html`: File utama yang berisi seluruh struktur HTML, styling CSS (internal), dan logika JavaScript untuk website portofolio.

## 🚀 Cara Menjalankan Secara Lokal
1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/hannabil/portfolio-new-jihan.git
   ```
2. **Buka folder proyek:**
   ```bash
   cd portfolio-new-jihan
   ```
3. **Buka file di browser:**
   Klik dua kali pada file `index.html` atau klik kanan dan pilih "Open with Browser" (Chrome, Edge, atau Safari).

## 🛠 Cara Memperbarui Konten
Jika Anda ingin mengubah teks atau gambar di portofolio:
1. Edit file `index.html` menggunakan text editor (seperti VS Code).
2. Simpan perubahan.
3. Unggah kembali ke GitHub dengan perintah:
   ```bash
   git add index.html
   git commit -m "Update konten portofolio"
   git push origin main
   ```

## 🌐 Publikasi (GitHub Pages)
Untuk menampilkan website ini secara online:
1. Buka repositori di GitHub.
2. Pergi ke menu **Settings** > **Pages**.
3. Pada bagian **Branch**, pilih `main` dan folder `/ (root)`.
4. Klik **Save**.
5. Tunggu beberapa menit, dan website Anda akan aktif di URL yang disediakan GitHub.
